# @sintonia/mobile

The Expo app, iOS and Android. See the [root README](../../README.md) for how
the pieces fit together.

```bash
pnpm dev:mobile        # Metro
pnpm --filter @sintonia/mobile ios
pnpm --filter @sintonia/mobile android
```

Online play needs the room server running too:

```bash
pnpm dev:backend       # :1999
```
